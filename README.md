📝 Lista de Tareas GUI

Una aplicación de escritorio simple para gestionar tareas diarias, desarrollada en Python con Tkinter. Permite añadir, completar y eliminar tareas con una interfaz intuitiva y controles de teclado/ratón.
Características principales:

➕ Añadir tareas (Enter o botón)

✅ Marcar completadas (doble clic o botón)

🗑️ Eliminar tareas con confirmación

📱 Interfaz responsive y fácil de usar****
